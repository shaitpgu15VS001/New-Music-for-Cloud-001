הורדה מיוטיוב — מדריך מקוצר

מדריך זה הוא סקירה קצרה. לפרטים מלאים — המדריך המורחב.

מה זה

סקריפט הורדה מיוטיוב ויוטיוב מיוזיק שפועל בשתי שכבות גיבוי, ללא צורך בחשבון גוגל:

  • שכבה 1 — yt-dlp עם לקוחות שמאומתים לעבוד מ-IPs של דאטה סנטר (בלי PO Token ובלי חשבון)
  • שכבה 2 — cobalt API ציבורי: אם שכבה 1 נחסמת, עוברים ל-instance קהילתי ללא טוקן

מצב נוכחי: הבדיקות רצות דרך proxy חינמי של Cloudflare WARP שמתבצע בתוך ה-runner עצמו — כך ש-YouTube רואה כתובת יציאה שאינה חסומה. לפרטים: docs/STATUS.html.

הרצה מקומית

./scripts/download.sh "https://www.youtube.com/shorts/GTgarjAw8b8" video 1080
./scripts/download.sh "https://music.youtube.com/watch?v=XXXX" audio 320
./scripts/download.sh "https://music.youtube.com/watch?v=XXXX" audio 320 square

הפרמטרים: קישור, מצב (video או audio), איכות (מספר או max), ופרמטר רביעי אופציונלי לצורת תמונת הקאבר: full (ברירת מחדל) או square. הקובץ נשמר בתיקיית downloads/.

במצב audio הקובץ יורד עם תמונת הקאבר של השיר מוטמעת בתוכו — היא מופיעה בנגני מדיה ובטלפון בלי צורך בקובץ תמונה נפרד. לבחירת ריבוע שווה-מרכז במקום המלבן המלא — הוסיפו square כפרמטר רביעי (או עמודה רביעית square ברשימה).
מטא-דאטה מלא — ללא הגדרה: כל קובץ אודיו יורד עם כותרת, אמן, תאריך, ז'אנר וקישור למקור (מיוטיוב). אם הקובץ הוא שיר מוכר, נוסף אוטומטית גם אלבום, תאריך שחרור ומספר רצועה — מתוך מאגר iTunes החינמי, ורק אם אורך השיר תואם. הכול מוצג בשורת מטא-דאטה: … בקובץ quality.txt.
שם הקובץ ותגית "הערות": שם הקובץ מכיל את כותרת הסרטון בלבד — לדוגמה שלוש עשרה מידות.mp3. מזהה הסרטון אינו מופיע בשם; הוא נשמר בתגית הערות בפורמט מזהה | קישור, לדוגמה bNpTG31hVEM | https://www.youtube.com/watch?v=bNpTG31hVEM. כך יודעים מאיזה סרטון נגזר הקובץ, גם בלי להסתכל בשם.

הרצה מ-GitHub Actions

  1. דחפו את הפרויקט ל-repo ב-Gיטאב
  2. בכרטיסיית Actions בחרו בדיקת הורדה דרך WARP proxy (הניסוי הנוכחי)
  3. לחצו Run workflow — ניתן להשאיר את ברירות המחדל (3 בדיקות במקביל)
  4. בתום הריצה, הורידו את ה-Artifact כדי לראות את האיכות בפועל

קיים גם workflow ישן בשם בדיקת הורדה מיוטיוב (test-download.yml) ללא פרוקסי — למעקב אחרי ההבדל בין ריצה ישירה לריצה דרך WARP.

workflow ההפקה — הורדה אוטומטית

בנוסף ל-workflow הבדיקה, קיים workflow הפקה קבוע בשם הורדת יוטיוב (הפקה) (download.yml) שמוריד סרטונים לפי רשימה. הוא כולל את כל המנגנונים המוכחים: WARP, לולאת סיבוב IP עד 3 נסיונות, אימות סיומת ו-ffmpeg אוטומטי.

כלי העבודה

  • קובץ הרשימה — downloads-list.txt בשורש ה-repo. כל שורה = קישור + מצב (video/audio) + איכות (מספר או max) + צורת קאבר אופציונלית (full/square, לאודיו בלבד). ברירות מחדל: video, 1080 ו-full. שורות ריקות ושורות שמתחילות ב-# מתעלמות
  • קלט ידני — בעת הרצה ידנית ניתן להזין קישור נוסף (+מצב, איכות וצורת קאבר) בשדות הקלט — הוא מתווסף לרשימה לאותה ריצה בלבד
  • תזמון אוטומטי — הריצה היומית בשעה 03:00 UTC (05:00 שעון ישראל) מעבדת את מה שנשאר ברשימה
# דוגמה ל- downloads-list.txt
https://www.youtube.com/watch?v=dQw4w9WgXcQ video 1080
https://music.youtube.com/watch?v=XXXX audio 320
https://www.youtube.com/watch?v=YYYY audio 320 square
# https://www.youtube.com/watch?v=YYYY  <- שורה זו מושבתת
חשוב: מומלץ למחוק כל שורה מהרשימה אחרי שההורדה הצליחה — כדי שהריצה היומית לא תוריד שוב את אותו סרטון. כל הורדה מוצלחת מועלית כ-Artifact בתוקף 30 יום.

פתרון תקלות

  • שלב "בדיקת WARP" נכשל ב workflow — ה-proxy לא עלה או שהתעבורה לא יצאה דרך WARP. בדקו ב-LOG את קובץ wireproxy.log שמוצג בשגיאה. לעתים קרובות ריצה חוזרת פותרת
  • "Sign in to confirm you're not a bot" — yt-dlp לא עבד דרך הפרוקסי או שהכתובת שנבחרה חסומה. בדקו ב-LOG שהופיעה שורת "yt-dlp עובד דרך פרוקסי"
  • cobalt החזיר שגיאת auth — ה-instance הוסיף הגנה. בדקו docs/STATUS.html לinstancות עדכניות
  • הקובץ ירד אבל ריק/קטן — לרוב האיכות שביקשת אינה זמינה. נסו איכות נמוכה יותר או מצב audio
מגבלה ידועה: instancות cobalt הקהילתיות עלולות ליפול ללא התראה. זה בדיוק תפקיד השכבה הראשונה (yt-dlp), שהיא עצמאית לחלוטין. המעקב אחרי מצב המערכת נמצא ב-docs/STATUS.html.
