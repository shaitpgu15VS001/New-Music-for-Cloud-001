הורדה מיוטיוב — מצב הפרויקט

עודכן: 2026-11-01

1. סקירה

מטרת הפרויקט: אוטומציית הורדה מיוטיוב ויוטיוב מיוזיק שתפעל מ-GitHub Actions ללא קוקיז של חשבון גוגל. הקושי המרכזי: YouTube חוסם IP של דאטה סנטר ("Sign in to confirm you're not a bot"). הדרישות: וידאו, YouTube Music ו-Shorts באיכות רגילה (לא נמוכה), ללא אימות טלפון בפלטפורמת משנה.

2. מצב נוכחי

שתי שיטות קודמות נפסלו (PO Token — איכות נמוכה בלבד; Replit — אימות טלפון). הכיוון הנוכחי: ניסוי Cloudflare WARP כ-proxy בתוך ה-runner של GitHub Actions. הוכנו: סקריפט הורדה מתוקן עם תמיכת פרוקסי + workflow ניסוי חדש. ממתינים להרצה ראשונה.

3. פתוח כרגע

  1. דחיפה ל-repo והרצה ידנית של test-warp-download.yml
  2. בדיקת שלב 2 ב-workflow: האם כתובת היציאה אכן משתנה ב-runner (warp פעיל)
  3. בדיקת שלוש הבדיקות: Shorts 1080p, וידאו max, אודיו מ-YouTube Music
  4. אם הצלחה: העברת התמיכה ב-WARP ל-workflow ההפקה + תכנון טריגר schedule
  5. אם כשלון: מעבר ל-runner ביתי (self-hosted) כפתרון מפלט ודאי

4. החלטות והנימוקים

החלטהנימוקחלופות שנדחו
הכיוון הנוכחי: Cloudflare WARP בתוך GitHub Actions חינם, ללא חשבון/טלפון, אינו משנה את ארכיטקטורת הפרויקט, מוכח בשימוש אמיתי בשרתי דאטה סנטר (בלוג arfevrier 2025, repo yt-dlp-rescue 2026) פרוקסי חינמיים ציבוריים (לא יציבים, חסומים גם הם); פלטפורמות ענן אחרות (אותה בעיית IP דאטה סנטר)
תוכנית מפלט: runner ביתי (self-hosted) IP רשת ביתית לא נחסם — ודאות גבוהה; דורש מחשב דולק + repo פרטי מסיבות אבטחה נפסל כשלב ראשון כי דורש מהמשתמש תשתית והגבלות אבטחה
נטישת שיטת PO Token (bgutil) הניסיון המעשי: לא הוריד YouTube Music ולא Shorts, ומה שהורד — באיכות נמוכה מאוד בלבד השארת השיטה עם שיפורים (המשתמש החליט)
נטישת ארכיטקטורת Replit Replit התחילה לאמת מספר טלפון — תנאי בל יעבור של המשתמש isActive API של Replit נבדק חייתית וקיים (2026-11-01), אך חסר ערך עקב דרישת הטלפון
שכבה שנייה: cobalt בinstancות קהילתיות נותרה כנפילה בסקריפט ללא שינוי Invidious/Piped — שרתי מתים או חסומים

5. ממצאים מאומתים

  • מאומת 2026-11-01: WARP עוקף חסימת YouTube משרתי דאטה סנטר — ראיות: blog.arfevrier.fr (יולי 2025, שרתי Oracle) ו-repo CRtheHILLS/yt-dlp-rescue (מרץ 2026) — שניהם מתעדים yt-dlp עובד דרכו. לא נבדק עדיין בגיטאב אקשנס עצמו.
  • מאומת 2026-11-01: הגרסאות העדכניות של הכלים: wgcf v2.3.1 ו-wireproxy v1.1.3 — נבדקו מול GitHub API, הקבצים קיימים להורדה. בארשייב של wireproxy קובץ בינארי יחיד wireproxy.
  • מאומת 2026-11-01: wireproxy תומך בייבוא קונפיג WireGuard בפורמט wg-quick (אותו פורמט ש-wgcf מייצר) ובקבוצות [Socks5] / [http] — לפי README הרשמי. נבחר [http] כי yt-dlp תומך ב-proxy HTTP ללא תלות נוספת (pysocks).
  • מאומת 2026-11-01: API של Replit קיים בפועל (replit.com/api/v1/repls מחזיר 401/403 למפתח שגוי, 404 ללא אימות) — אך חסר ערך עקב אימות הטלפון.
  • נשלל 2026-11-01: api.replit.com/v1 — זהו Admin API ל-Enterprise فقط (מפרט ה-OpenAPI שלו מצהיר: "Enterprise Account analytics and administration"), אינו מתאים למשתמש פרטי.
  • נשלל: Invidious/Piped — 401/403 או "Sign in to confirm". instance api.cobalt.tools — דורש Turnstile והסיר יוטיוב.
