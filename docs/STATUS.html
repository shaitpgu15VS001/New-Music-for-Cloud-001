הורדה מיוטיוב — מצב הפרויקט

עודכן: 2026-11-01

1. סקירה

מטרת הפרויקט: אוטומציית הורדה מיוטיוב ויוטיוב מיוזיק שתפעל מ-GitHub Actions ללא קוקיז של חשבון גוגל. הקושי המרכזי: YouTube חוסם IP של דאטה סנטר ("Sign in to confirm you're not a bot"). הדרישות: וידאו, YouTube Music ו-Shorts באיכות רגילה (לא נמוכה), ללא אימות טלפון בפלטפורמת משנה.

2. מצב נוכחי

הרצה ראשונה של הניסוי הושלמה (2026-11-01): WARP מוכח עובד בגיטאב אקשנס — warp=on, כתובות יציאה שונות בכל ריצה, וסרטון אחד ירד בהצלחה מלאה. שני הכשלים בבדיקה זו לא נבעו מחסימת IP אלא משני באגים מקומיים — שתוקנו. המתנה להרצה שנייה (עם התיקונים + מטריצה מורחבת) ולתרשים השוואה מול ריצה ללא פרוקסי.

3. פתוח כרגע

  1. דחיפה ל-repo והרצה במקביל של שני ה-workflows על אותו commit: test-download.yml (בלי פרוקסי) מול test-warp-download.yml (עם WARP) — אותה מטריצה של 5 בדיקות
  2. השוואת תוצאות: אם הריצות דומות — ייתכן שחסימת ה-IP פחותה ממה שחשבנו; אם הריצה ללא פרוקסי נכשלת במקומות שה-WARP עובר — מוכח שצריך אותו
  3. אחרי ההשוואה: החלטה סופית אם WARP הוא השיטה הקבועה או גיבוי
  4. תכנון טריגר schedule ושאר שלבי האוטומציה

5. ממצאים מאומתים

  • מאומת מהרצה 2026-11-01: WARP עובד בגיטאב אקשנס — שלב בדיקת ה-proxy החזיר warp=on בשתי ריצות, עם כתובות יציאה שונות בכל ריצה (IPv6). ריצה ללא פרוקסי באותו commit: כתובת ה-runner ישירה (52.250.233.128 וכו').
  • מאומת מהרצה 2026-11-01: הורדה מלאה דרך WARP — "Me at the zoo" ירד ב-629KB בבדיקה "וידאו רגיל max". yt-dlp עבד דרך 127.0.0.1:1080 (השורה "yt-dlp עובד דרך פרוקסי" בlog).
  • מאומת מהרצה 2026-11-01: באג --merge-output-format m4a — yt-dlp דוחה ערך זה ("invalid merge output format") — כל הורדת אודיו הייתה נופלת תמיד, גם ללא פרוקסי. תוקן ל--f ba/b -x --audio-format mp3|m4a.
  • מאומת מהרצה 2026-11-01: שתי כשלוניות בדיקות לא נבעו מחסימת IP: Shorts — ה-proxy לא עלה תוך 30 שניות (תקלת תשתית); Music — באג הפרמטר m4a לעיל. בדיקת ה-Shorts לא הגיעה כלל ל-yt-dlp.
  • שאלה פתוחה (2026-11-01): "Me at the zoo" ירד גם בריצות קודמות ללא WARP — ייתכן שחסימת ה-IP של GitHub חלקית/הסתברותית ולא גורפת. תיבדק בהשוואת שתי הריצות על אותו commit.
  • מאומת 2026-11-01: הגרסאות העדכניות של הכלים: wgcf v2.3.1 ו-wireproxy v1.1.3 — נבדקו מול GitHub API, הקבצים קיימים להורדה. בארשייב של wireproxy קובץ בינארי יחיד wireproxy.
  • מאומת 2026-11-01: wireproxy תומך בייבוא קונפיג WireGuard בפורמט wg-quick (אותו פורמט ש-wgcf מייצר) ובקבוצות [Socks5] / [http] — לפי README הרשמי. נבחר [http] כי yt-dlp תומך ב-proxy HTTP ללא תלות נוספת (pysocks).
  • מאומת 2026-11-01: API של Replit קיים בפועל (replit.com/api/v1/repls מחזיר 401/403 למפתח שגוי, 404 ללא אימות) — אך חסר ערך עקב אימות הטלפון.
  • נשלל 2026-11-01: api.replit.com/v1 — זהו Admin API ל-Enterprise فقط (מפרט ה-OpenAPI שלו מצהיר: "Enterprise Account analytics and administration"), אינו מתאים למשתמש פרטי.
  • נשלל: Invidious/Piped — 401/403 או "Sign in to confirm". instance api.cobalt.tools — דורש Turnstile והסיר יוטיוב.
